## Lernziele

Nach dieser Übung kannst du

- erklären, wie der Volume Shadow Copy Service (VSS) Momentaufnahmen eines Laufwerks erstellt,
- Schattenkopien für ein Laufwerk aktivieren, den Speicherplatz begrenzen und einen Zeitplan setzen,
- eine Schattenkopie manuell erstellen,
- als Benutzer eine frühere Version einer Datei über den Reiter *Vorgängerversionen* wiederherstellen.

## Voraussetzungen

- Modul 02 abgeschlossen. `\\FS1\Unternehmensdaten\Vertrieb` ist für `Sales_User` beschreibbar.
- Hyper-V-Checkpoint `m02-ende`.

## Grundbegriffe

| Begriff | Bedeutung |
|---|---|
| **VSS** | Volume Shadow Copy Service. Erstellt konsistente Momentaufnahmen eines Laufwerks, ohne dass Dateien geschlossen sein müssen. |
| **Schattenkopie** | Eine solche Momentaufnahme. Sie speichert nur geänderte Datenblöcke, nicht das ganze Laufwerk. |
| **Schattenkopiespeicher** | Bereich, in dem die geänderten Blöcke liegen. Seine Größe lässt sich begrenzen. Ist er voll, werden die ältesten Schattenkopien gelöscht. |
| **VSS-Provider** | Komponente, die die Momentaufnahme technisch erstellt. Der Standardprovider von Windows arbeitet softwarebasiert. |
| **Vorgängerversionen** | Anzeige der Schattenkopien einer Datei oder eines Ordners im Explorer. |

## Aufgabe

### Teil 1: Schattenkopien aktivieren und planen (auf FS1)

*(Lerneinheit 3.1 und 3.2, Praxisaufgabe 1)*

**1. Aktivieren**

Menüweg: *Explorer → Dieser PC → Rechtsklick auf Laufwerk C: → Eigenschaften → Reiter Schattenkopien → C: markieren → Aktivieren*. Beim Aktivieren legt Windows sofort eine erste Schattenkopie an. Bestätige die Rückfrage.

**2. Speicherplatz begrenzen**

Im selben Reiter: *Einstellungen → Maximale Größe → Grenzwert*, z. B. 2000 MB (im Labor genügt wenig). Die Größe ist deine Wahl, nicht Teil des Lehrplans. PowerShell/Kommandozeile:

```powershell
vssadmin list shadowstorage
vssadmin resize shadowstorage /for=C: /on=C: /maxsize=2GB
```

**3. Zeitplan 07:00 und 12:00 prüfen und setzen**

Im selben Dialog: *Einstellungen → Zeitplan*. Laut Erfahrung legt Windows beim Aktivieren zwei Zeitpläne an (07:00 und 12:00, Montag bis Freitag). Prüfe, ob das so ist (*nicht bestätigt*). Falls nicht, lege zwei Zeitpläne an: 07:00 und 12:00 Uhr.

**4. Prüfen**

```powershell
vssadmin list shadows
```

Erwartet (*sinngemäß*): mindestens eine Schattenkopie für `C:\` mit Erstellungszeit. Notiere die Anzahl.

### Teil 2: Testdatei, manuelle Schattenkopie, Änderung

*(Praxisaufgabe 2; die Reihenfolge ist wichtig)*

**1. Datei anlegen (auf CL1 als `CORP\Sales_User`)**

Lege in `\\FS1\Unternehmensdaten\Vertrieb` die Datei `Test.txt` mit dem Inhalt `Version 1` an:

```powershell
Set-Content -Path '\\FS1\Unternehmensdaten\Vertrieb\Test.txt' -Value 'Version 1'
Get-Content '\\FS1\Unternehmensdaten\Vertrieb\Test.txt'
```

**2. Manuelle Schattenkopie (auf FS1), erst nach dem Anlegen der Datei**

```powershell
vssadmin create shadow /for=C:
vssadmin list shadows
```

Erwartet (*nicht bestätigt*): eine neue Schattenkopie mit aktuellem Zeitstempel. `vssadmin create shadow` gibt es laut Erfahrung nur auf Serverversionen von Windows. Notiere den Zeitstempel.

**3. Datei ändern (auf CL1)**

```powershell
Set-Content -Path '\\FS1\Unternehmensdaten\Vertrieb\Test.txt' -Value 'Version 2'
Get-Content '\\FS1\Unternehmensdaten\Vertrieb\Test.txt'
```

Erwartet: `Version 2`.

### Teil 3: Wiederherstellung durch den Endanwender (auf CL1)

*(Lerneinheit 3.3, Praxisaufgabe 3)*

**1. Vorgängerversionen anzeigen**

Menüweg: *Explorer → `\\FS1\Unternehmensdaten\Vertrieb` → Rechtsklick auf `Test.txt` → Eigenschaften → Reiter Vorgängerversionen*. Dort steht mindestens eine Version mit dem Zeitstempel der manuellen Schattenkopie (*nicht bestätigt*; die Anzeige braucht manchmal einige Sekunden).

**2. Inhalt prüfen, dann wiederherstellen**

Markiere die Version, wähle *Öffnen* und prüfe den Inhalt: `Version 1`. Wähle dann *Wiederherstellen*, bestätige die Rückfrage und lies die Datei erneut:

```powershell
Get-Content '\\FS1\Unternehmensdaten\Vertrieb\Test.txt'
```

Erwartet: `Version 1`. Mit *Kopieren* kannst du die alte Version stattdessen an einen anderen Ort legen und die aktuelle Datei behalten. Das ist im Alltag oft der bessere Weg.

## Hinweise

- Schattenkopien liegen auf **demselben Laufwerk** wie die Daten (hier `C:`). Fällt das Laufwerk aus, sind Daten und Schattenkopien weg. Das ist kein Ersatz für eine Sicherung.
- Der Reiter *Vorgängerversionen* zeigt nur Schattenkopien, die **nach** dem Anlegen der Datei entstanden sind. Wer die Reihenfolge in Teil 2 vertauscht, sieht nichts.
- Wird der Speicher knapp, löscht Windows die ältesten Schattenkopien zuerst. Die Anzahl der Versionen ist also nicht fest, sondern hängt von Größe und Änderungsmenge ab.
- Windows hält höchstens 64 Schattenkopien je Laufwerk (Wert aus dem Kenntnisstand, *nicht bestätigt*).

## Kontrollfragen

1. Ersetzt der Volume Shadow Copy Service (VSS) ein externes Backup-System? Begründe.
2. Wo werden die Schattenkopien standardmäßig gespeichert und wie kann man Speicherplatzprobleme verhindern?
3. Welche Rolle spielt der VSS-Provider bei der Erstellung der Schattenkopie?

## Musterlösung

<details>
<summary>Antworten und Zielzustand (erst nach dem Versuch öffnen)</summary>

**Zielzustand**

- Auf `C:` von `FS1` sind Schattenkopien aktiv, mit Größenbegrenzung und Zeitplan 07:00 und 12:00.
- `Test.txt` enthält nach der Wiederherstellung wieder `Version 1`.

**Antworten**

1. **Nein.** Schattenkopien liegen auf demselben Laufwerk wie die Originaldaten und schützen deshalb nicht vor Plattenausfall, Verlust des Servers oder Ransomware auf dem Server. Sie ergänzen eine Sicherung um eine schnelle Wiederherstellung durch die Benutzer.
2. Standardmäßig im Schattenkopiespeicher **auf demselben Laufwerk** (Volume). Du begrenzt ihn über *Einstellungen → Maximale Größe* bzw. `vssadmin resize shadowstorage` oder lagerst ihn auf ein anderes Laufwerk aus.
3. Der Provider erzeugt die Momentaufnahme: Er sorgt dafür, dass Änderungen nach dem Zeitpunkt in den Speicher geschrieben werden, damit der alte Stand erhalten bleibt. Der Standardprovider von Windows arbeitet mit Software. Hardwareprovider von Speichersystemen können das auslagern.

</details>

## Erweiterungen

- Lege eine zweite Version an (`Version 3`, dann manuelle Schattenkopie, dann `Version 4`) und stelle gezielt eine mittlere Version wieder her.
- Lösche `Test.txt` als `Sales_User` und stelle sie über den Reiter *Vorgängerversionen* des **Ordners** `Vertrieb` wieder her.
- Verkleinere den Schattenkopiespeicher stark (`vssadmin resize shadowstorage ... /maxsize=...`) und beobachte, ab wann die ältesten Schattenkopien verschwinden.
