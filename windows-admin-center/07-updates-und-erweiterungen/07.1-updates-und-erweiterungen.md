Gegen Microsoft Learn gelesen (12.11.2026): Funktionen des Werkzeugs *Updates*, Reiter *Available extensions*, *Installed extensions*, *Feeds*, Ordnerfeed (Ablage nicht unter `C:\Users`, Zugriff für Network Service), Update-Regeln des Gateways. **Nicht bestätigt:** die Ausgabe von „Online prüfen“ ohne Internet, die genaue `icacls`-Syntax für das Konto „Network Service“, das Verhalten bei einem leeren Feed und die Anzeige im Gateway nach dem Entfernen. Das Labor hat kein Internet; Online-Funktionen werden nur beschrieben.

## Lernziele

Nach dieser Übung kannst du

- das Werkzeug *Updates* bedienen und erklären, welche Quellen im Labor fehlen
- installierte Erweiterungen anzeigen und einen Feed auf einer Dateifreigabe einrichten und entfernen
- die Aktualisierung des Gateways selbst einordnen

## Voraussetzungen

- Module 02 und 03 abgeschlossen.

## Grundbegriffe

| Begriff | Bedeutung |
|---|---|
| Updates (Werkzeug) | Zeigt verfügbare und installierte Updates, Verlauf, Prüfung bei Microsoft Update. |
| Feed | Quelle, aus der das Gateway Erweiterungen bezieht; NuGet-Feed oder Ordner. |
| Offline-Feed | Ordner mit signierten Paketen, die vorab aus dem öffentlichen Feed geladen wurden. |
| Update-Regel | Nur die neueste Version ohne Vorschau wird unterstützt; Update binnen 30 Tagen. |

## Testumgebung

| Gerät | Rolle in Modul 07 |
|---|---|
| WAC01 | Gateway, Feed-Ordner |
| ZIEL01 | Ziel des Werkzeugs *Updates* |

## Aufgabe

### Teil 1: Updates ansehen

*(Lerneinheit 7.1, Praxisaufgabe 1)*

Öffne bei `ziel01.wac.internal` das Werkzeug *Updates*. Sieh dir den Verlauf an und vergleiche mit:

```powershell
Get-HotFix | Sort-Object InstalledOn
```

Löse „Online prüfen“ aus. Das Labor hat kein Internet; erwartet wird kein Ergebnis oder eine Fehlermeldung (Wortlaut nicht bestätigt).

### Teil 2: Update-Quellen (schriftlich)

*(Praxisaufgabe 2)*

Erkläre in einem Absatz, welche Quellen ein produktiver Server hätte: Microsoft Update, WSUS, die Azure-Update-Verwaltung. Die Azure-Integration wird nicht geübt; laut Microsoft Learn setzt sie die Registrierung des Gateways bei Azure voraus.

### Teil 3: Erweiterungen ansehen

*(Lerneinheit 7.2, Praxisaufgabe 3)*

Öffne die Einstellungen, Bereich *Extensions*, und liste die installierten Erweiterungen. Notiere, warum *Available extensions* im Labor leer bleibt oder einen Fehler zeigt (kein Internet; nicht bestätigt).

### Teil 4: Offline-Feed

*(Praxisaufgabe 4)*

Auf `WAC01`:

```powershell
New-Item -Path C:\WACFeed -ItemType Directory
icacls C:\WACFeed /grant "NT AUTHORITY\NETWORK SERVICE:(OI)(CI)RX"
```

Die Syntax für das Konto ist nicht bestätigt; prüfe das Ergebnis mit `icacls C:\WACFeed`. Der Ordner liegt bewusst nicht unter `C:\Users`. Trage ihn unter *Feeds* ein und notiere das Ergebnis; der Ordner ist leer, weil es offline keine signierten Pakete gibt. Entferne den Feed danach wieder:

```powershell
Remove-Item C:\WACFeed -Recurse
```

### Teil 5: Gateway aktualisieren (schriftlich)

*(Lerneinheit 7.3, Praxisaufgabe 5)*

Beschreibe, wie das Gateway aktualisiert wird (neues Installationsprogramm oder Microsoft Update, laut Microsoft Learn), und was dabei mit Port und Zertifikat passiert. Laut der Known-Issues-Seite kann beim Wechsel von 2311 auf 2410 das Zertifikat nicht übernommen werden; verweise auf Modul 05.

## Hinweise

- Dieses Modul ist optional (Priorität 2). Kein Pflichtmodul setzt es voraus.
- Entferne den Feed am Ende wieder, damit der Zustand dem von Modul 06 entspricht.
- Keine Pakete aus unbekannten Quellen in einen Feed legen.

## Kontrollfragen

1. Warum zeigt das Werkzeug *Updates* im Labor keine verfügbaren Updates?
2. Wie gelangt eine Erweiterung in eine Umgebung ohne Internetzugang?
3. Warum prüfst du nach einem Gateway-Update das Zertifikat?
4. Was bedeutet „Update binnen 30 Tagen“ für die Betriebsplanung?

## Musterlösung

<details>
<summary>Antworten und Zielzustand (erst nach dem Versuch öffnen)</summary>

**Zielzustand**

- Updates-Werkzeug und Verlauf gesehen, Erweiterungsliste notiert, Ordnerfeed angelegt und wieder entfernt, `C:\WACFeed` gelöscht.

**Antworten**

1. Es gibt keine Verbindung zu Microsoft Update und keinen WSUS im Labor.
2. Das Paket wird aus dem öffentlichen Feed geladen, in einen Ordner gelegt und dieser als Feed eingetragen (laut Microsoft Learn signierte `.nupkg`-Dateien).
3. Beim Update kann das Zertifikat nicht übernommen werden (bekanntes Problem 2311 → 2410); ein erneuter Test des Browsers zeigt es.
4. Nach Erscheinen einer neuen Version muss das Gateway innerhalb von 30 Tagen aktualisiert werden, sonst verliert es den Support.

</details>
