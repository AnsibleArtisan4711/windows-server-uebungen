Notiere Fehlermeldungen wörtlich.

## Lernziele

Nach dieser Übung kannst du

- die Voraussetzung „verschachtelte Virtualisierung“ herstellen
- die Hyper-V-Rolle im Windows Admin Center installieren und die Werkzeuge *Virtual switches* und *Virtual machines* bedienen
- eine leere VM anlegen, starten, beenden und löschen und die Grenze zum Hyper-V-Kurs benennen

## Voraussetzungen

- Modul 03 abgeschlossen.
- Prüfpunkt `vor-M8` auf beiden VMs vor Beginn.

## Grundbegriffe

| Begriff | Bedeutung |
|---|---|
| Verschachtelte Virtualisierung | Eine VM stellt selbst Hyper-V bereit; der Host muss die Erweiterung für die VM freischalten. |
| Virtual switches | Werkzeug zum Anlegen, Umbenennen und Löschen von Hyper-V-Switches. |
| Virtual machines | Werkzeug zum Anzeigen und Verwalten von VMs. |

## Testumgebung

| Gerät | Rolle in Modul 08 |
|---|---|
| Host | Freischaltung der Virtualisierung |
| WAC01 | Gateway und Browser |
| ZIEL01 | Zielserver mit Hyper-V |

## Aufgabe

### Teil 1: Ausgangslage und Host-Einstellung

*(Lerneinheit 8.1, Praxisaufgabe 1)*

Auf dem Host:

```powershell
foreach ($vm in 'WAC01','ZIEL01') { Checkpoint-VM -Name $vm -SnapshotName 'vor-M8' }
Stop-VM -Name ZIEL01
Set-VMProcessor -VMName ZIEL01 -ExposeVirtualizationExtensions $true
Start-VM -Name ZIEL01
```

### Teil 2: Hyper-V-Rolle installieren

*(Praxisaufgabe 2)*

Installiere im Werkzeug *Roles & features* die Rolle **Hyper-V** auf `ZIEL01` (Neustart). Prüfe:

```powershell
Get-WindowsFeature Hyper-V
```

Ob die Installation in der verschachtelten VM gelingt, ist nicht bestätigt. Notiere eine Fehlermeldung wörtlich.

### Teil 3: Virtuellen Switch anlegen

*(Lerneinheit 8.2, Praxisaufgabe 3)*

Lege im Werkzeug *Virtual switches* einen privaten Switch `vSwitch-Geschachtelt` an. Prüfe:

```powershell
Get-VMSwitch
```

### Teil 4: Leere VM

*(Praxisaufgabe 4)*

Lege im Werkzeug *Virtual machines* eine leere Generation-2-VM `test-vm01` ohne Betriebssystem an (Assistent nicht bestätigt), starte und beende sie und lösche sie danach samt Festplatte.

### Teil 5: Rückbau und Abgrenzung

*(Lerneinheit 8.3, Praxisaufgabe 5)*

Lösche den Switch `vSwitch-Geschachtelt`. Setze beide VMs gemeinsam auf `vor-M8` zurück. Notiere schriftlich zwei Dinge, die der Hyper-V-Kurs behandelt und die hier nicht.

## Hinweise

- Dieses Modul ist optional (Priorität 2). Kein Pflichtmodul setzt es voraus.
- Setze beide VMs immer gemeinsam zurück.
- Die Übung erzeugt keine echte Arbeitslast; sie zeigt nur die Bedienung.

## Kontrollfragen

1. Warum ist für Hyper-V in einer VM die Option der verschachtelten Virtualisierung nötig?
2. Welche Aufgaben lassen sich im Werkzeug *Virtual machines* ausführen, und welche würdest du im Hyper-V-Manager oder per PowerShell erledigen?
3. Warum gehört das Modul zur Priorität 2?
4. Warum setzt du beide VMs gemeinsam auf `vor-M8` zurück?

## Musterlösung

<details>
<summary>Antworten und Zielzustand (erst nach dem Versuch öffnen)</summary>

**Zielzustand**

- Verschachtelung freigeschaltet, Rolle installiert (oder Fehlermeldung dokumentiert), Switch und VM angelegt und wieder entfernt, beide VMs auf `vor-M8` zurückgesetzt.

**Antworten**

1. Ohne die Erweiterung sieht die VM die Virtualisierungsfunktionen der CPU nicht und kann Hyper-V nicht starten.
2. Bedienung von Switches und VMs im Browser; spezielle Einstellungen, Skripte und große Mengen eher im Hyper-V-Manager oder per PowerShell. Die Antwort ist offen.
3. Er ist für die Kernkompetenz nicht nötig und braucht verschachtelte Virtualisierung, die nicht jeder Host bietet.
4. Damit das Gateway und das Ziel denselben Zeitstand haben; ein einzelner Rücksetzer kann Zustand und Verbindung verschieben.

</details>
