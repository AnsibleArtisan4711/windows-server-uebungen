# Modul 01: Security Baseline

Dauer laut Skript: 10 Unterrichtsstunden (Annahme: 1 Stunde je Richtlinie, siehe Einleitung). Priorität: überwiegend 1 (zwei Richtlinien mit Priorität 2).

Das zugehörige Kapitel des Skripts: [skript.md](skript.md) (aus LaTeX umgewandelt). Jede Richtlinie hat einen Steckbrief, eine Erklärung, ein Beispiel, typische Fehler und einen Praxisbezug. Am Ende des Kapitels stehen Übungsaufgaben und getrennt dahinter die Lösungen.

## Richtlinien

- 1: Kontosperrungsschwelle setzen (Prio 1)
- 2: Kontosperrdauer setzen (Prio 1)
- 3: Kennwortlänge erhöhen (Prio 1)
- 4: Kennwortverlauf erzwingen (Prio 2)
- 5: Gastkonto deaktivieren (Prio 1)
- 6: Lokales Administratorkonto umbenennen (Prio 2)
- 7: UAC für Administratoren aktivieren (Prio 1)
- 8: UAC sichere Desktopaufforderung (Prio 1)
- 9: Anonyme SID-Auflösung verhindern (Prio 1)
- 10: LAN Manager Hash Speicherung verhindern (Prio 1)
