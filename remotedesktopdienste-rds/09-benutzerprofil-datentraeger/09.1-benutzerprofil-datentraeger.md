# 09.1 Profilverwaltung mit Benutzerprofil-Datenträgern (UPD): Freigabe, Aktivierung, Nachweis

| | |
|---|---|
| **Modul** | 09 Profilverwaltung mit Benutzerprofil-Datenträgern |
| **Stufe** | Fortgeschritten (Priorität 1) |
| **Geschätzte Zeit** | 5 bis 6 Stunden (Schätzung; Lehrplan: 8 UE zu 45 Minuten = 6 Stunden) |
| **Werkzeuge** | Server-Manager, Windows PowerShell, `icacls`, `mstsc` |
| **Vorwissen** | Modul 04 |

> [!WARNING]
> **Stand der Prüfung: Entwurf, nicht im Labor ausgeführt.** `Set-RDSessionCollectionConfiguration` mit `-EnableUserProfileDisk`, `-DiskPath`, `-MaxUserProfileDiskSizeGB` und der Weg *Collections → Desktop → Properties → User Profile Disks* stammen aus Microsoft Learn (12.11.2026). **Nicht bestätigt:** Name und Ort der `.vhdx`-Datei, Verhalten bei vollem Datenträger, Rechte im Detail (die Quelle verlangt Vollzugriff für die Server der Sammlung). `DC01` als Speicherort ist eine Laborvereinfachung.

## Lernziele

Nach dieser Übung kannst du

- erklären, was ein Benutzerprofil-Datenträger ist und welche Grenzen er hat
- eine Freigabe für UPDs anlegen und UPDs für eine Sammlung aktivieren
- nachweisen, dass Daten nach Abmeldung und Neuanmeldung erhalten bleiben

## Voraussetzungen

- Modul 04 abgeschlossen (Sammlung `Desktop` ohne UPD).

## Grundbegriffe

| Begriff | Bedeutung |
|---|---|
| UPD | Benutzerprofil-Datenträger: pro Benutzer und Sammlung eine VHD(X)-Datei auf einer zentralen Freigabe, die bei der Anmeldung eingebunden wird. |
| Computerkonto | Konto `RDS01$`; auf ihm laufen die Dienste, die auf die Freigabe zugreifen. |

## Testumgebung

| Gerät | Rolle in Modul 09 |
|---|---|
| DC01 | Freigabe `UPD` (Laborvereinfachung) |
| RDS01 | Session Host |
| CL01 | Anmeldung |

## Aufgabe

### Teil 1: Freigabe

*(Lerneinheit 9.1 und 9.2, Praxisaufgabe 1)*

Auf `DC01`:

```powershell
New-Item -Path 'C:\UPD' -ItemType Directory
New-SmbShare -Name 'UPD' -Path 'C:\UPD'
Grant-SmbShareAccess -Name 'UPD' -AccountName 'RDSLAB\RDS01$' -AccessRight Full -Force
icacls 'C:\UPD' /grant 'RDSLAB\RDS01$:(OI)(CI)F'
```

Dateidienste sind nicht Teil dieses Kurses; `DC01` als Speicherort ist eine Laborvereinfachung. Die Quelle verlangt, dass die Server der Sammlung auf der Freigabe Vollzugriff haben.

### Teil 2: UPD aktivieren

*(Praxisaufgabe 2)*

```powershell
Set-RDSessionCollectionConfiguration -CollectionName 'Desktop' -EnableUserProfileDisk -DiskPath '\\dc01.rdslab.internal\UPD' -MaxUserProfileDiskSizeGB 5 -ConnectionBroker 'rds01.rdslab.internal'
```

Oder in Server Manager: *Collections → Desktop → Properties → User Profile Disks*.

### Teil 3: Nachweis

*(Praxisaufgabe 3)*

Melde dich als `user1` an, lege eine Datei auf dem Desktop an und ändere eine Einstellung (zum Beispiel den Hintergrund). Melde dich ab und wieder an. Prüfe, dass beides erhalten ist, und sieh in `C:\UPD` auf `DC01` nach der `.vhdx`-Datei (Name *nicht bestätigt*).

### Teil 4: Grenzen

*(Lerneinheit 9.3, Praxisaufgabe 4)*

Schreibe auf, warum ein UPD nur innerhalb einer Sammlung gilt (laut Quelle liegt `C:\Users\<Benutzer>` einschließlich `AppData\Local` auf dem UPD) und welche Folgen das bei mehreren Sammlungen hat.

## Hinweise

- Lege keine produktiven Daten in das Labor. UPDs enthalten die gesamte Benutzerumgebung.
- Lege Inhalte der Freigabe nicht in ein Repository.

## Kontrollfragen

1. Wo liegt ein UPD, und wann wird er in die Sitzung eingebunden?
2. Warum können UPDs nicht zwischen Sammlungen wandern?
3. Was bewirkt die Größenbegrenzung, und was passiert, wenn der Datenträger voll ist (nicht bestätigt)?

## Musterlösung

<details>
<summary>Antworten und Zielzustand (erst nach dem Versuch öffnen)</summary>

**Zielzustand**

- Freigabe `UPD` auf `DC01`, UPD für `Desktop` aktiviert, Datei und Einstellung nach Neuanmeldung erhalten, `.vhdx` auf der Freigabe sichtbar.

**Antworten**

1. Auf einer zentralen Freigabe; bei der Anmeldung wird die Datei in die Sitzung eingebunden und als lokales Laufwerk behandelt.
2. Weil das gesamte Benutzerverzeichnis, einschließlich der lokal gebundenen Anwendungsdaten, auf dem UPD liegt; ein anderer Session Host einer anderen Sammlung erwartet eine andere Konfiguration (laut Microsoft Learn „roamen nur innerhalb einer Sammlung“).
3. Sie begrenzt den Speicher je Benutzer. Was bei vollem Datenträger geschieht, ist nicht bestätigt; sinngemäß treten Schreibfehler in der Sitzung auf.


</details>
