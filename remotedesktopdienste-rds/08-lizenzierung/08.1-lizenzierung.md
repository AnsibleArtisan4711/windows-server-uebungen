> [!WARNING]
> **Stand der Prüfung: Entwurf, nicht im Labor ausgeführt.** Lizenzmodelle, Grace-Zeitraum (120 Tage), Lizenzmodus unter *Edit Deployment Properties → RD Licensing*, die drei Aktivierungswege und die Versionsregeln stammen aus Microsoft Learn (12.11.2026). `GetGracePeriodDays`, `GetSpecifiedLicenseServerList` und `LicensingType` über WMI stehen im Troubleshooting-Artikel. **Nicht bestätigt:** `Add-RDServer` für die Lizenzrolle, die Ausgabe der WMI-Aufrufe, der Anzeigetext im RD Licensing Manager für „nicht aktiviert“. **Im isolierten Labor ist keine Aktivierung und keine CAL-Installation möglich.**

## Lernziele

Nach dieser Übung kannst du

- die Lizenzmodelle „pro Benutzer“ und „pro Gerät“ vergleichen und für ein Szenario begründet wählen
- den Lizenzserver installieren, den Lizenzmodus festlegen und den Grace-Zeitraum auslesen
- den Ablauf von Aktivierung und CAL-Installation beschreiben (Theorie)

## Voraussetzungen

- Modul 06 abgeschlossen.
- Das Labor hat kein Internet. Eine Aktivierung ist deshalb nicht ausführbar.

## Grundbegriffe

| Begriff | Bedeutung |
|---|---|
| CAL | Client Access License: Lizenz für den Zugriff eines Benutzers oder Geräts auf einen Session Host. |
| Pro Benutzer | Lizenz an einen Benutzer im AD gebunden; Überbelegung technisch möglich, aber lizenzrechtlich nicht erlaubt. |
| Pro Gerät | Lizenz an ein Gerät gebunden; temporäre CAL für 90 Tage bis zur Vergabe. |
| Grace-Zeitraum | 120 Tage ohne Lizenzserver. |
| Aktivierung | Verbindung des Lizenzservers mit dem Microsoft Clearinghouse. |

|---|---|
| RDS01 | Lizenzrolle |

## Aufgabe

### Teil 1: Modell wählen (schriftlich)

*(Lerneinheit 8.1, Praxisaufgabe 1)*

Wähle für drei Szenarien (Schichtbetrieb mit gemeinsamen Geräten; Mitarbeitende mit eigenem Gerät; gemischt) das Modell und begründe. Beachte laut Microsoft Learn: In der Domäne sind beide Modelle möglich, in einer Arbeitsgruppe nur „pro Gerät“.

### Teil 2: Lizenzserver installieren

*(Lerneinheit 8.2, Praxisaufgabe 2)*

*Server Manager → Remote Desktop Services → Overview → + RD Licensing*, Server `RDS01`. Alternativ (Rollenwert *nicht bestätigt*):

```powershell
Add-RDServer -Server 'rds01.rdslab.internal' -Role 'RDS-LICENSING' -ConnectionBroker 'rds01.rdslab.internal'
```

### Teil 3: Lizenzmodus festlegen

*(Praxisaufgabe 3)*

*Edit Deployment Properties → RD Licensing*, **Per User** wählen, `rds01.rdslab.internal` als Lizenzserver hinzufügen.

### Teil 4: Grace-Zeitraum und Lizenzstatus

*(Praxisaufgabe 4)*

In Windows PowerShell (5.1) auf `RDS01`, Aufrufe laut Microsoft Learn:

```powershell
$obj = Get-WmiObject -Namespace 'Root/CIMV2/TerminalServices' -Class Win32_TerminalServiceSetting
$obj.GetGracePeriodDays()
$obj.GetSpecifiedLicenseServerList()
$obj.LicensingType
```

Öffne danach den *RD Licensing Manager* (*Server Manager → Tools → Remote Desktop Services → Remote Desktop Licensing Manager*) und notiere, dass der Server **nicht aktiviert** ist.

### Teil 5: Aktivierung beschreiben

*(Lerneinheit 8.3, Praxisaufgabe 5)*

Beschreibe schriftlich: die drei Wege (automatisch, Webbrowser, Telefon), den Schritt „Install licenses“, und warum nichts davon im Labor möglich ist. Nenne, was du in der Praxis brauchst (Lizenzprogramm, Lizenzcode oder Vertragsnummer). Beachte die Versionsregel: Die CAL-Version muss zum Session Host passen und darf nicht neuer sein als die des Lizenzservers.

## Hinweise

- Alle Lizenzaussagen gelten für das Labor mit Evaluationssoftware. Für den Produktivbetrieb entscheiden Vertrag und Lizenzbedingungen.
- Setze den Grace-Zeitraum nicht zurück; Microsoft empfiehlt es laut Troubleshooting-Artikel nicht.

## Kontrollfragen

1. Was geschieht, wenn der Grace-Zeitraum endet und kein Lizenzserver mit CALs erreichbar ist?
2. Warum zeigt der Server den Grace-Zeitraum auch nach dem Hinzufügen des Lizenzservers weiter an?
3. Worin unterscheiden sich pro Benutzer und pro Gerät bei Entziehung und Überbelegung?
4. Welche drei Möglichkeiten gibt es, einen Lizenzserver zu aktivieren?

## Musterlösung

<details>
<summary>Antworten und Zielzustand (erst nach dem Versuch öffnen)</summary>

**Zielzustand**

- Lizenzrolle installiert, Modus „Per User“ gesetzt, Lizenzserver eingetragen, Grace-Zeitraum ausgelesen, Notiz zur Aktivierung ohne Ausführung.

**Antworten**

1. Clients brauchen laut Microsoft Learn eine gültige CAL von einem Lizenzserver, sonst können sie sich nicht an einer Remotesitzung anmelden.
2. Solange der Server nicht aktiviert ist und keine CALs ausstellen kann, gilt der Grace-Zeitraum weiter (sinngemäß, nicht im Labor beobachtet).
3. Pro Gerät: bis zu 20 % der CALs lassen sich laut Learn entziehen, keine Überbelegung. Pro Benutzer: keine Entziehung, Überbelegung technisch möglich, aber ein Lizenzverstoß.
4. Automatische Verbindung (TCP 443 zum Clearinghouse), Webbrowser, Telefon.


</details>
