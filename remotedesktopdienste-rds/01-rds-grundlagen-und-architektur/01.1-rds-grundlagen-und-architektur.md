## Grundbegriffe

| Begriff | Bedeutung |
|---|---|
| RD Session Host | Server, auf dem die Benutzersitzungen laufen (Desktop oder RemoteApp). |
| RD Connection Broker | Verteilt Verbindungen auf die Session Hosts einer Sammlung und stellt unterbrochene Sitzungen wieder her. |
| RD Web Access | Webseite, über die Benutzer ihre Desktops und RemoteApps starten. |
| RD Gateway | Tunnelt RDP über HTTPS, damit der Zugriff von außen ohne VPN möglich ist. |
| RD Licensing | Lizenzserver, der RDS-CALs (Client Access Licenses) ausstellt und verwaltet. |
| Grace-Zeitraum | Laut Microsoft Learn 120 Tage, in denen kein Lizenzserver nötig ist. |

## Musterlösung

<details>
<summary>Antworten und Zielzustand (erst nach dem Versuch öffnen)</summary>

**Zielzustand**

- Eine beschriftete Zeichnung, eine Vergleichstabelle und drei datierte Notizen mit Quellen.

**Antworten**

1. Der Broker verteilt Verbindungen auf die Session Hosts einer Sammlung und verbindet Benutzer nach einer Unterbrechung wieder mit ihrer bestehenden Sitzung. Laut Microsoft Learn (RDS-Rollen) braucht ein Bereitstellungsmodell mit Sammlungen ihn; die Bereitstellungsassistenten legen ihn immer an.
2. Beim Desktop sieht der Benutzer eine komplette Serveroberfläche, beim RemoteApp nur das Fenster der einzelnen Anwendung, die dennoch auf dem Server läuft.
3. 120 Tage. Danach brauchen Clients laut Microsoft Learn eine gültige RDS-CAL von einem Lizenzserver, um sich anmelden zu können.
4. Fällt der eine Server aus oder wird er kompromittiert, fallen alle Rollen aus. Außerdem sollte ein Gateway im Randnetz stehen und ein Domänencontroller keine Sitzungen hosten.

**Beispiel für Teil 1 (stark vereinfacht):**

```text
Internet/Außen --HTTPS (443, nicht bestätigt)--> RD Gateway --RDP (3389, nicht bestätigt)--> RD Session Host
Browser --HTTPS (443, nicht bestätigt)--> RD Web Access --> RD Connection Broker --> RD Session Host
RD Session Host --> RD Licensing (Lizenzabfrage)
alle Server --> DC (Anmeldung, DNS)
```

**Zu Teil 3:** Laut Microsoft Learn (Seite vom 13.10.2026) ist Windows Server 2022 seit dem 13.10.2026 im erweiterten Support (Sicherheitsupdates bis 14.10.2031). Trage dein Lesedatum ein.


</details>
